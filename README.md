# site-assets

Static assets for https://hougaard.lakebed.app - currently the converted STEP edge models.

`climate-march-evidence.html` is the password-free Climate March source finder.
It contains 40 passage options across eight topics, APA 7 references under each
option, and 24 genuine browser screenshots of openly licensed or U.S. federal
government source text. Other passages link to the original source. Wikipedia
references and passage links pin the September 4, 2026 archived revision.
